# BluePixel — motion brand sheet

Source: "BluePixel Product Reel — Production Document" (design system verified from dev.bluepxl.com)
and the BluePixel brand voice notes. Update this file when the locked brand fact sheet is final.

## Colour
| Token | Hex | Use |
|---|---|---|
| paper | `#FAF7F2` | default canvas, with blue dot grid `rgba(14,165,233,0.25)` every 28px |
| navy | `#1A1A2E` (panel `#0F1629`→`#121E2B`) | transitions, taglines, AI / term-cycling beats only |
| blue | `#0EA5E9` | primary accent |
| gradient | `#0EA5E9`→`#5DAE50` at 135° | progress ring, confidence/score bars, kinetic type |
| amber | `#F59E0B`→`#B86E00` | one CTA per film, nothing else |

## Type
- Display + big numerals: **Barlow Semi Condensed** 700/800, tight tracking (files in `assets/fonts/`).
- UI / body / labels: **Inter**.

## Motifs to reuse
- Giant outlined section numerals (01–09).
- Progress pill / ring filling in the brand gradient.
- Floating cards with soft shadow and slight rotation.
- "LIVE" and "AI" pills; green "AI NATIVE" sparkle badge.
- Score bars and confidence bars sweep left→right; KPIs count up; empty "—" fields snap to values.
- Logo: pixelated navy "B" with one blue pixel cut, wordmark BLUE PIXEL, sub-line PROPERTY INTELLIGENCE LAYER.
  The demo film draws an approximation — **replace with the official SVG** in `assets/logo.svg` when available.

## Story building blocks
- The 4-step ring: **Connect → Enrich → Predict → Deliver**.
- Pain: scattered CRE data, high-stakes decisions. Bridge: **"Buy it. Then fill it."**
- AI transparency: source citations and confidence scores.
- Positioning: works alongside LoopNet and Crexi, not against them.

## Rules
- Voice: warm, founder-like, restrained. Banned: "revolutionary", "game-changing", "seamless", "unlock".
- URL is **bluepxl.com**. CTA currently "Start free" (confirm with the team).
- Stats (data-source count, AI confidence %) are inconsistent across materials — don't put a number on
  screen until it's in the locked fact sheet. No real client names, emails, addresses or dollar figures.
- No people, faces or hands in product films unless the brief says so.
